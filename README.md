# Elda Circular 2026 ♻️ (Civic OS)

Portal dinámico para la gestión de residuos e innovación ciudadana en Elda, España. Este proyecto es una herramienta de ingeniería social y financiera diseñada para maximizar el ahorro municipal y fomentar el civismo.

## 🚀 Objetivo Estratégico
Transformar a Elda en una ciudad de **Residuo Cero**, reduciendo los costes de vertido en Villena mediante un sistema de trazabilidad y meritocracia (Elda-Coins).

## 🏗️ Estructura del Proyecto (Fase 1)
- `/docs`: Documentación técnica, legal y estrategias de ahorro (>90€/ton).
- `/src/data`: JSONs con los puntos de recogida de las "Esquinas de Quita y Pon".
- `/src/components`: UI de la PWA (React + Vite + Lucide).
- `/public/media`: Activos multimedia y educativos (Generación Z-ero).

## 🛠️ Stack Tecnológico
- **Frontend:** React.js con Vite.
- **Iconografía:** Lucide React.
- **Estética:** Boogie Pop Art (Colores de alto contraste).
- **Despliegue:** Preparado para Vercel / GitHub Pages.
